# ExamLex 前端升级说明

## 🎨 核心概念：学习之河

这次升级将 ExamLex 的用户界面转化为一个"学习之河"的可视化系统，用流动的河流隐喻代替传统的数据面板。

## ✨ 主要改进

### 1. 河流可视化系统 (river.js)

**核心装置**：可交互的 Canvas 河流图

- **五个能力节点**：沿河道从上游到出海口分布（词汇→阅读→听力→翻译→写作）
- **50个流动粒子**：象征学习轨迹的水滴
- **实时脉动动画**：节点呼吸效果
- **水波纹交互**：鼠标悬停产生涟漪
- **60fps 性能**：流畅的动画体验

### 2. 增强的微交互

- **任务完成动画**：粒子爆炸特效
- **模块卡片悬停**：抬升 + 缩放效果
- **记忆卡翻转**：3D 卡片动画
- **模态框进入**：滑入 + 缩放组合

### 3. 流体动画系统

所有过渡使用自定义 cubic-bezier 缓动，模拟水流的自然运动。
