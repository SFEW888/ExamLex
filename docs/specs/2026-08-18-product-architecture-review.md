# ExamLex 产品架构与首页审查稿

状态：Design Review（设计审查），未进入前端、后端或数据实现。

## 核心概念

ExamLex 是一张会随学习证据持续改写的“备考路线图”。资料不是独立陈列的教材，写作、听力、阅读、翻译、词汇中的每次学习、练习、错误和复习都会落成可追溯节点；系统据此组织下一步，而不是只展示功能入口。

## 用户主路径

```text
选择考试 -> 查看今日路线 -> 进入五项学习模块 -> 真题/模拟训练
         -> 产生作答证据 -> 错因诊断 -> 生成记忆卡 -> 间隔复习
         -> 每日总结与计划调整
```

## 一级功能

1. `今日路线`：今日概览、待办、学习热力图、五项掌握度、今日名言、考试倒计时。
2. `五项学习`：写作、听力、阅读、翻译、词汇；教材知识点直接进入对应模块。
3. `基础知识`：词性、句型、语音三组基础内容，作为五项学习的共享前置能力。
4. `真题演练`：仅收录题目级来源可核验的历年真题，展示 `official_verified` 状态。
5. `模拟特训`：用户上传或 ExamLex 生成，始终展示 `simulation_not_official` 状态。
6. `文档上传`：支持 Word、Excel、PDF、TXT、Markdown 和图片；先隔离解析，再由用户确认入库。
7. `记忆卡`：从考点、错题和已确认文档生成；采用可解释、可版本化的间隔复习调度。
8. `错题与证据`：记录答案、定位依据、错因、题型和薄弱能力，驱动后续训练。
9. `每日总结`：自动聚合学习时长、完成量、正确率、错因和次日计划。
10. `成就激励`：段位、徽章墙和个人历史排名，不引入公开社交竞争。
11. `AI 助教`：支持 OpenAI、DeepSeek、Kimi、GLM、Claude 兼容接口及第三方中转；密钥仅由本地后端管理。

## 内容组织决策

- 前台不设置 `source_role=教材讲解`，也不建立“教材讲解”栏目。
- 教材内容拆成 `ContentUnit` 后，按能力目标直接进入写作、听力、阅读、翻译、词汇或基础知识。
- 后台保留不可见的 `source_refs`、页码、文件 hash、OCR 置信度、校对状态和版权状态。
- OCR 内容在人工校对前只能是 `draft`；教材中的题目不能仅凭教材页面自动标为官方真题。

## 视觉与交互原则

- 采用安静、编辑式、工作台风格；纸张底色、炭黑、朱红、墨绿和琥珀形成多色但克制的体系。
- 首屏中心是 `Evidence Route`：五项模块不是孤立卡片，而是同一条学习路线上的可操作节点。
- 章节状态连续：完成练习后，路线节点、今日计划、记忆卡和掌握度同步变化。
- 主要动效不是批量淡入；路线在“计划生成 -> 任务推进 -> 错因转折 -> 今日收束”中连续编排。
- 键盘、触控和 `prefers-reduced-motion` 均保留完整状态反馈； reduced-motion 下以离散状态替代连续运动。

## 主动不做

1. 不做“教材书架”：资料来源不是学习目标，避免把产品退化为文件阅读器。
2. 不把 AI 聊天作为首页中心：AI 必须基于当前题目、来源和个人证据工作。
3. 不在首版做公开社区、好友 PK 和公开卡组：先保证个人学习闭环、版权边界和内容质量。

## V3 -> V4 自审与重构记录

- 概念是否贯穿：V3 的 `Memory Ribbon` 只表达学习历史，V4 将其重构为 `Evidence Route`，把计划、五项能力、错因和复习放进同一条路线，概念从装饰图形变成信息结构。
- 是否有模板感：V3 仍接近通用学习仪表盘；V4 用考试路线、来源状态和模块内容替代泛化的功能卡，减少“课程、商城、社区”式入口。
- 是否有无意义动效：后续实现只允许路线节点因任务状态变化而运动；不采用批量 `opacity + translateY` reveal，静态稿已经明确开始、推进、转折、收束四个状态。
- 首屏是否有记忆点：中央连续路线和五个能力节点形成识别点；右侧今日计划让视觉装置立即承担行动，不是单纯背景。
- 信息是否易懂：首屏以“今天该做什么”开头，模块卡直接写出题型和下一步；官方真题、非官方模拟、隔离上传使用不同状态标签，避免来源混淆。
- 移动端和可访问性是否成立：实现阶段需将路线改为纵向时间线，任务列表保持单列；所有节点必须有文字标签、键盘焦点和 `aria-label`，`prefers-reduced-motion` 下只保留离散状态变化。
- 性能是否合理：核心路线使用 CSS/SVG 轻量绘制，不引入 Three.js 或持续粒子；后台 OCR、AI 和文档解析均异步化，前端只接收摘要和已授权来源。

本轮实质性重构：移除“教材讲解”信息层级、将五项内容升为首屏一级入口、把真题/模拟/上传的证据边界前置，并将记忆卡收束为到期复习入口。

## 审查边界

本稿只确认信息架构、视觉方向和状态边界。用户确认前不创建前端页面、不修改后端 schema、不导入 OCR 草稿为正式内容。
